# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in a SANAD Digital project, please report it privately through GitHub's private vulnerability reporting mechanism when available.

You may also contact:

developers@sanad.digital

Please include:

- The affected repository and version.
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any relevant proof of concept.

Please give the maintainers reasonable time to investigate and address the issue before publicly disclosing the vulnerability.
